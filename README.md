# Erwin Paisal

Landing page profesional Erwin Paisal, Head of Information Technology @ Victoeria Vicci.

## Konten

Seluruh konten halaman utama berada di [js/data.js](js/data.js). Ubah data tersebut lalu deploy ke GitHub Pages. Data hanya boleh memuat informasi, proyek, dan klaim yang sudah disetujui untuk dipublikasikan.

Form kontak tidak menyimpan data pengunjung. Setelah dikirim, pengunjung diarahkan ke WhatsApp dengan draft pesan yang dapat mereka tinjau sebelum mengirimnya.

## Menjalankan lokal

```bash
python3 -m http.server 8080
```

Buka `http://localhost:8080/`.
